ZX81 Fold

A little computer from 1981, reborn for Android.

ZX81 Fold is a free, open-source Sinclair ZX81 emulator for Android, developed by JaySoft.

Originally conceived for a Samsung Galaxy Fold, the project recreates the experience of using Sir Clive Sinclair's iconic home computer, complete with its original BASIC ROM, ZX81-inspired keyboard, cassette storage and wonderfully imperfect television display.

Built for nostalgia, curiosity and the simple pleasure of making old technology come alive again.

Features

- Authentic ZX81 emulation — Z80 processor emulation, genuine Sinclair BASIC ROM and 16K RAM configuration.
- ZX81-inspired 40-key keyboard — responsive touchscreen buttons arranged in the original ZX81 configuration, with recreated BASIC keywords, functions, legends and graphics symbols. The current keyboard uses individual, slightly rounded rectangular keys rather than the original one-piece membrane design.
- Virtual cassette recorder — load and save ZX81 programs through a retro-inspired datacorder interface. 
- Four display presets — Original, Warm CRT, Aged CRT and Green Screen.
- Adjustable CRT effects — live phosphor bloom and blur controls, with independently remembered settings.
- Foldable-friendly interface — responsive display and keyboard layouts, including an adjustable screen/keyboard divider.
- Offline operation — no account, advertisements or internet connection required to use the emulator.
- Hands-on workshop — a substantial workshop experience that brings the project to life and gives users a closer look at how the emulator, interface and retro-computing experience were developed.

Release 1.0 RC1

This is our first release candidate, developed and tested primarily on a Samsung Galaxy Fold.

BASIC, cassette operations, keyboard functions and several original 16K games have been successfully tested, including 3D Monster Maze.

Compatibility with other Android devices is one of the main objectives of this initial community release.

Installation

1. Download the signed APK from the GitHub Releases section when available.
2. Open the APK on your Android device.
3. Allow installation from your chosen file manager if Android requests permission.
4. Launch ZX81 Fold and enjoy!

Note: An existing debug-signed installation may need to be removed before installing this release. Export any saved programs first.

Community testing

We welcome feedback from Sinclair enthusiasts, original ZX81 owners and anyone interested in retro computing.

We're particularly interested in display scaling, keyboard usability, compatibility with original ZX81 BASIC programs and performance on different Android devices.

Please report issues through GitHub Issues, including your Android device model and version.

Future development

Potential improvements include a landscape display mode featuring a faithful recreation of the original Sinclair ZX81 membrane keyboard, further interface refinements and expanded device compatibility.

These are development ideas rather than features included in RC1.

Our immediate priority is stability, authenticity of emulation and feedback from early testers.

A little background

This project began with a simple thought: wouldn't it be wonderful to turn a modern folding smartphone into the Sinclair ZX81 I remembered from childhood?

My original ZX81 didn't survive my curiosity. I dismantled it as a boy, determined to understand what was happening inside.

More than forty years later, that same curiosity led to ZX81 Fold.

What began as a personal experiment has become something I'd love to share with the people who remember these remarkable little machines.
